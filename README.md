# Boiler Room Academy

מערכת ניהול תלמידים — Boiler Room Trading Academy

## העלאה ל-GitHub Pages

1. צור Repository חדש ב-GitHub
2. העלה את הקובץ `index.html` לשורש ה-Repository
3. כנס ל-Settings → Pages
4. תחת "Source" בחר: **Deploy from a branch**
5. Branch: **main** | Folder: **/ (root)**
6. לחץ Save

האתר יהיה זמין בכתובת:
`https://[username].github.io/[repository-name]/`
